# 蒸馏 prompt（把聊天记录提炼成 L1–L4）

把下面这段提示词喂给你选择的 AI（ChatGPT / Claude / Gemini / DeepSeek 等），让它从你的聊天记录中提炼 L1–L4。把 `<聊天记录>` 替换成你在 `docs/intake.md` 指导下整理好的统一 Markdown。

---

你是「自我蒸馏」助手。请从下面提供的聊天记录中，提炼出关于使用者的 L1–L4 分级信息。

## L1–L4 定义

- **L1 协作契约**：怎么配合使用者（授权边界、汇报习惯、反馈信号、表达偏好）
- **L2 决策逻辑**：使用者怎么判断（取舍原则、优先级、红线）
- **L3 个人事实**：使用者是谁（身份、经历、偏好等）
- **L4 领域打法**：使用者可复用的工作方法（某领域的方法论、写作风格、经验）

## 规则

1. 只提炼聊天记录中**明确出现**的信息，不推测、不编造、不补全。
2. 每条尽量附来源（哪条消息、时间）和状态（`confirmed` / `待确认`）。
3. 无法确认的信息标注「待确认」，不要当成事实写死。
4. 敏感信息（健康/财务/家庭/身份细节）单独归到 L3 的「敏感信息」区，并标注 `[SENSITIVE]`。
5. 输出按 selfdistill 的 canonical 结构：`01-l1-contract.md` / `02-l2-decision-logic.md` / `03-l3-user-profile.md` / `04-domain-playbooks/*.md`（每个领域一个文件，frontmatter 含 `id` + `description`）。

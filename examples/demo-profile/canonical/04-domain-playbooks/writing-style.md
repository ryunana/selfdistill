# [SIMULATED] Writing Demo

- [SIMULATED] Put the useful answer before background explanation.
- [SIMULATED] Name the user, action, condition, and result when they matter.
- [SIMULATED] Keep limitations and failed attempts visible.
- [SIMULATED] Prefer a plain accurate sentence to a polished unsupported claim.

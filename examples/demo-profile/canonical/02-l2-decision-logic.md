# [SIMULATED] Demo 决策逻辑（L2）

> 本页只展示“决策规则如何被结构化”，所有内容均为虚构示例。

## 需求取舍

- [SIMULATED] 先确认目标用户和必须解决的问题，再讨论功能。
- [SIMULATED] 一次只承诺少量高优先级范围，其余明确延后。
- [SIMULATED] 指标必须说明时间窗口、样本和计算口径。

## 方案判断

- [SIMULATED] 优先选择可验证、可撤回的方案。
- [SIMULATED] 数据不足时先补证据，不用流畅表达掩盖空白。
- [SIMULATED] 动态价格、规则和开放状态以实时查询为准。

## 冲突处理

1. [SIMULATED] 先列出冲突的事实和约束。
2. [SIMULATED] 标明哪些是用户已确认内容。
3. [SIMULATED] 未确认部分保留为候选，不自动写入。
